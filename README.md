# The Lost & Found Bureau 🕵️

A dark-themed, interactive detective storytelling website where a missing object leads to a mysterious case. Explore clues, question suspects, uncover unexpected twists, and choose your own ending through a chapter-based scrolling experience.

### Built With
- HTML5
- CSS3
- Git and GitHub

**Goal:** To create an immersive storytelling experience that blends mystery, creativity, and interactive design.
